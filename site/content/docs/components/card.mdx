---
title: Card
description: A boxed surface from the article element, with an optional header and footer.
---

An `<article>` is a card. A `<header>` or `<footer>` as a direct child becomes a full-width band with its own background and a border toward the body. Nothing else is needed.

<Example title="Card" height={300}>
```html
<article>
  <header>Header</header>
  Body of the card.
  <footer>Footer</footer>
</article>
```
</Example>

Header and footer are optional, and you can use either one alone.

<Example title="Body only and header only" height={300}>
```html
<article>A card with only a body.</article>
<article>
  <header>Header only</header>
  Body text.
</article>
```
</Example>

## Cards in a grid

Put cards in a `.grid` to place them side by side. The grid is part of the class build.

<Example title="Cards in a grid" height={260}>
```html
<div class="grid">
  <article>
    <header>One</header>
    First card.
  </article>
  <article>
    <header>Two</header>
    Second card.
  </article>
</div>
```
</Example>

## Cards in other places

The same surface is used inside a [modal](/docs/components/modal), where the `<article>` is the dialog box, and inside a bare popover, where an `<article>` child turns the popover into a card (see [Popover patterns](/docs/components/popover)). A card with `aria-busy="true"` shows a spinner, see [Loading](/docs/components/loading).

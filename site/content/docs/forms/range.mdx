---
title: Range
description: A slider with a styled track and thumb in Chromium, WebKit and Firefox.
---

`input[type="range"]` is full width with a thin track and a round thumb. The thumb grows slightly while it is dragged.

<Example title="Range" height={140}>
```html
<label>
  Volume
  <input type="range" name="volume" min="0" max="100" value="40" />
</label>
```
</Example>

## Accessibility

Give the slider a label. For a value that matters, show it in an `output` element linked with `for`, so the number is readable without dragging.

<Example title="Range with output" height={180}>
```html
<form oninput="level.value = volume.value">
  <label for="volume">Volume</label>
  <input type="range" id="volume" name="volume" min="0" max="100" value="40" />
  <output name="level" for="volume">40</output>
</form>
```
</Example>

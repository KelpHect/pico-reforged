---

Add `role="switch"` to a checkbox and it is drawn as a toggle. It is still a checkbox, so it submits and works with the keyboard the same way, and the role tells assistive technology it is a switch.

<Example title="Switch" height={170}>
```html
<fieldset>
  <label>
    <input name="terms" type="checkbox" role="switch" />
    I agree to the Terms
  </label>
  <label>
    <input name="opt-in" type="checkbox" role="switch" checked />
    Receive news and offers
  </label>
</fieldset>
```
</Example>

## Disabled and invalid

<Example title="Disabled and invalid" height={230}>
```html
<fieldset>
  <label>
    <input type="checkbox" role="switch" disabled />
    Disabled
  </label>
  <label>
    <input type="checkbox" role="switch" checked disabled />
    Disabled, on
  </label>
  <label>
    <input type="checkbox" role="switch" aria-invalid="true" />
    Invalid
  </label>
</fieldset>
```
</Example>

Examples

Plain pages that load the built CSS from ../css/. Run pnpm build first, then open any of them in a browser. No server and no build step.

  • Basic page: class build, buttons, cards, accordion, dropdown, modal
  • Classless page: semantic HTML only
  • Forms: every input type and the validation states
  • Dashboard: app shell, data table, tabs, toasts and other extras
  • Popover patterns: dropdown menu, tooltips, exclusive accordion, modal
  • Custom theme: one brand color with relative color syntax

examples/vite and examples/next are small apps that show the build integrations.
